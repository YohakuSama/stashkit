# StashKit self-hosted strategy icons

The original 39 icons were imported from LoonKit at [`d82214d057b27a68d6b9c07c61fb126a69adc903`](https://github.com/YohakuSama/loonkit/tree/d82214d057b27a68d6b9c07c61fb126a69adc903/icons).

38 of those upstream PNGs remain byte-for-byte unchanged. `HBO.png` has been replaced with a clearer HBO Max icon. The 39 active group icons are referenced from immutable asset commit `3778671c7d4141ac49d734a8dfd45452a5147949` and verified against the hashes in [`build/icon-lock.json`](../build/icon-lock.json).

These icons live in StashKit to avoid runtime dependencies on the original repository. See the [license](../LICENSE) and [third-party notices](../docs/THIRD_PARTY_NOTICES.md).
