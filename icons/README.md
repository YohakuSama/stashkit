# StashKit self-hosted strategy icons

The 39 PNG icons in this directory were copied byte-for-byte from LoonKit at [`d82214d057b27a68d6b9c07c61fb126a69adc903`](https://github.com/YohakuSama/loonkit/tree/d82214d057b27a68d6b9c07c61fb126a69adc903/icons).

Each PNG preserves its upstream Git blob SHA. The `ALL` strategy group intentionally reuses `Proxy.png` because no original `ALL.png` exists.

These files live in StashKit to avoid any runtime dependency on the original repository. See the repository [license](../LICENSE) and [third-party notices](../docs/THIRD_PARTY_NOTICES.md).
